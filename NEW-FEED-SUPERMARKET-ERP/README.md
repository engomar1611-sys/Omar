# NEW FEED SUPERMARKET ERP

مشروع نظام تخطيط موارد وتشغيل سوبرماركت متكامل.

## نطاق المشروع المعتمد
- واجهات عربية RTL مع دعم الإنجليزية، والعملة الأساسية الجنيه المصري.
- نقطة بيع POS متعددة الكاشيرات، مع السلة والخصومات وطرق الدفع وتعليق الفواتير وإعادة الطباعة.
- المنتجات والأصناف والتصنيفات والعلامات التجارية والوحدات والأوزان والعبوات والباركود.
- دعم البيع بالوزن وباركود الميزان وطباعة ملصقات الباركود بأحجام متعددة.
- المشتريات وطلبات الشراء والاعتمادات وأوامر الشراء والاستلام وفحص الجودة.
- المخازن وحركات الصنف والتشغيلات والصلاحية، ومتوسط التكلفة المرجح وFEFO ومنع المخزون السالب وبيع المنتهي.
- المبيعات والتحصيل والعملاء والموردون والخصومات والعروض والولاء.
- المرتجعات بموافقة فحص المخزن ثم الاعتماد المالي قبل رد المبلغ أو إعادة الصنف للمخزون الصالح.
- الحسابات العامة والقيود المزدوجة والخزائن والبنوك ومراكز التكلفة وإقفال الفترات.
- الموارد البشرية والأصول والصيانة والتوصيل والمتجر الإلكتروني وتطبيق العملاء والموظفين.
- الصلاحيات والأمان والنسخ الاحتياطي والاستعادة والتحديثات الآمنة وHTTPS.
- تكامل تشغيلي بين الموديولات واختبارات وحدات وتكامل.

## قرارات النطاق
- لا يتضمن المشروع موديول تقارير أو شاشات تقارير.
- لا تُنشأ أسعار أو أرصدة أو باركودات أو أوزان فعلية مفترضة؛ بيانات الأصناف التجارية يجب استيرادها من مصدر موثوق أو إدخالها واعتمادها.
- لا تُعتبر اختبارات Windows أو PostgreSQL أو أجهزة الكاشير والطابعات ناجحة إلا بعد تنفيذها فعليًا على بيئة الاختبار المستهدفة.

## حالة الملفات
هذا المجلد هو المساحة المخصصة للمشروع داخل المستودع. تم إنشاء هذا الملف التعريفي فقط؛ لم يتم إرفاق أرشيف التطبيق v0.4 أو رفع الشيفرة المصدرية في هذا الالتزام. يجب إضافة ملفات المصدر الفعلية ومراجعتها قبل اعتبار المستودع نسخة تشغيلية أو جاهزة للنشر.
