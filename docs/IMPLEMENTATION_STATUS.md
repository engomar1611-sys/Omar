- [x] تطبيق موظفين Windows مستقل ومثبت سيرفر Windows مدمجان في PR #31؛ نجح بناء ملفات EXE في GitHub Actions. لم يثبت بعد التشغيل على أجهزة Windows المستهدفة.

- [ ] تحديثات Windows موقعة رقمياً مع rollback؛ آلية الفحص والتنزيل والتحقق من توقيع الناشر موجودة، لكن إصدار شهادة Authenticode ونشر Release موقّع واختبار rollback الفعلي لم تتم بعد.
- [ ] اختبار طابعات A4 والحرارية والباركود والميزان والأجهزة الفعلية.

- [ ] جرد دوري/مفاجئ مع لقطة أرصدة وتسجيل فعلي واعتماد فروق الجرد؛ التنفيذ في PR #52 بانتظار CI والدمج.

- [x] إضافة قالب Caddy Reverse Proxy لـ HTTPS وتوثيق متطلبات DNS والمنافذ واختبارات القبول (PR #48، CI ناجح).

## حزمة الاختبار

أضيفت حزمة Docker Compose لتشغيل PostgreSQL 16 وAPI معاً على Windows، وسكربتات PowerShell لإنشاء المدير الأول والنسخ الاحتياطي والاستعادة. راجع `docs/TEST_DEPLOYMENT.md`.

نجاح CI على PR #48 تحقق من Backend CI وترحيلات PostgreSQL 16 وتهيئة أول مدير وبناء Docker، وكذلك اختبارات عميل Windows واختبارات تقوية الشبكة وبناء مثبتَي Windows. لا يثبت ذلك أن الواجهة جُرّبت على أجهزة العميل أو أن الطباعة والأجهزة الخارجية تعمل.

## بوابة القبول

لا تُستخدم بيانات إنتاج حقيقية قبل اجتياز خطة الاختبار، مراجعة القيود المحاسبية والمخزنية، واختبار HTTPS والنسخ والاستعادة والطباعة والصلاحيات على بيئة العميل. سجّل كل نتيجة قبول مع رقم إصدار ودليل.
