## ما لم يكتمل بعد — لا يُعلن جاهزاً للإنتاج

- [ ] برنامج Windows مستقل EXE/MSI؛ الموجود حالياً واجهة Web تعمل من متصفح Windows.
- [ ] HTTPS إنتاجي بشهادة موثوقة وتوزيع الثقة على أجهزة المستخدمين.
- [ ] تحديثات Windows موقعة رقمياً مع rollback.
- [ ] اختبار طابعات A4 والحرارية والباركود والميزان والأجهزة الفعلية.
- [ ] اختبار استعادة النسخ الاحتياطية عملياً على جهاز/قاعدة منفصلة.
- [ ] اختبارات قبول شاملة end-to-end على كل السيناريوهات وبكل الأدوار، بما فيها التزامن ومطابقة حركات المخزون مع الأستاذ.
- [ ] دفتر أستاذ تفصيلي وكشوف حساب ومطابقة أعمار أرصدة العملاء والموردين، مع مراجعة محاسبية نهائية.
- [ ] دورة تخطيط وجدولة مراحل المصنع وربط أجهزة التشغيل وبيانات القياس.
- [ ] اعتماد سياسات الجودة والتغذية والحدود الفنية لكل نوع علف من المختصين بالمصنع.
- [ ] اختبارات Windows Server/Windows client فعلية في بيئة العميل.

## حزمة الاختبار

أضيفت حزمة Docker Compose لتشغيل PostgreSQL 16 وAPI معاً على Windows، وسكربتات PowerShell لإنشاء المدير الأول والنسخ الاحتياطي والاستعادة. راجع `docs/TEST_DEPLOYMENT.md`.

نجاح CI يتحقق من اختبارات Node.js، وترحيل migrations على PostgreSQL 16، وتهيئة أول مدير، وبناء صورة Docker. لا يثبت ذلك أن الواجهة جُرّبت على أجهزة العميل أو أن الطباعة والأجهزة الخارجية تعمل.

## بوابة القبول

لا تُستخدم بيانات إنتاج حقيقية قبل اجتياز خطة الاختبار، مراجعة القيود المحاسبية والمخزنية، واختبار HTTPS والنسخ والاستعادة والطباعة والصلاحيات على بيئة العميل. سجّل كل نتيجة قبول مع رقم إصدار ودليل.
