# خطة الاختبار ومعايير القبول — NEW FEED ERP

## 1. منهجية الاختبار
لا يتم إعلان أي مرحلة مكتملة بمجرد نجاح تشغيل الواجهة. كل ميزة تمر بتحليل المتطلبات، اختبار وحدات، اختبار تكامل، اختبار صلاحيات، اختبار واجهة، ثم قبول المستخدم.

## 2. اختبارات وظيفية
- إنشاء أنواع أعلاف متعددة دون تعديل الكود.
- إنشاء منتجات وتركيبات مختلفة لكل نوع، وإصدار تركيبة جديدة مع حفظ التاريخ.
- منع استخدام تركيبة غير معتمدة أو منتهية.
- دورة شراء كاملة من الطلب إلى الاستلام والفاتورة والسداد.
- فحص خامات وحجز المرفوض منها ومنع صرفها للإنتاج.
- صرف خامات لأمر إنتاج ومقارنة المخطط بالفعلي وتسجيل الفاقد.
- فحص المنتج النهائي ومنع البيع قبل الإفراج عن التشغيلة.
- دورة بيع وتسليم وفاتورة وتحصيل ومرتجع.
- احتساب تكلفة فعلية للطن وتحليل فروق التكلفة.
- ترحيل القيود المزدوجة والتحقق من توازن كل قيد.
- عكس فاتورة/سند مع إعادة الأثر المخزني والمالي بصورة صحيحة.
- منع التعديل المباشر على المستندات المرحلة.
- تقارير المخزون والإنتاج والجودة والتكلفة والربحية والحسابات.

## 3. اختبارات سلامة البيانات والتزامن
- منع المخزون السالب.
- منع ترحيل المستند مرتين.
- اختبار مستخدمين يحاولان حجز/صرف آخر كمية متاحة بالتزامن.
- التحقق من أن الرصيد يطابق مجموع الحركات.
- التحقق من أن دفتر الأستاذ وميزان المراجعة متوازنان.
- التحقق من ربط كل دفعة بمصدرها ومراحل انتقالها.

## 4. الأمن والصلاحيات
- اختبار كل دور على الشاشات والإجراءات الحساسة.
- منع تجاوز الصلاحيات عبر استدعاء API مباشرة.
- اختبار كلمات المرور والجلسات ومحاولات الدخول.
- اختبار HTTPS والشهادات.
- اختبار سجل التدقيق للأحداث الحساسة.

## 5. التشغيل والاستمرارية
- تثبيت نظيف على Windows المستهدف.
- تشغيل تطبيق Windows والويب معاً على قاعدة بيانات واحدة.
- انقطاع الشبكة وإعادة الاتصال دون تكرار المعاملات.
- نسخ احتياطي واستعادة على بيئة منفصلة.
- تحديث إصدار ثم اختبار الرجوع للإصدار السابق.
- اختبار الطباعة والتصدير العربي PDF/Excel.
- اختبار حمل واقعي لعدد 10–30 مستخدماً.

## 6. أدلة القبول المطلوبة
لكل اختبار: رقم الحالة، المتطلبات المرتبطة، بيانات الاختبار، الخطوات، النتيجة المتوقعة، النتيجة الفعلية، حالة النجاح/الفشل، صورة أو سجل داعم، وإصدار البرنامج وقاعدة البيانات.

## 7. بوابات التسليم
- Gate 1: اعتماد المتطلبات والقرارات المفتوحة.
- Gate 2: اعتماد تصميم قاعدة البيانات والمعمارية.
- Gate 3: اكتمال الوحدات الأساسية واختبارات الوحدات.
- Gate 4: نجاح التكامل ودورات العمل الكاملة.
- Gate 5: نجاح الأمن والاستعادة والأداء والنشر.
- Gate 6: قبول المستخدم وتسليم الكود والتوثيق.

لا يجوز وصف المشروع بأنه جاهز للإنتاج قبل اجتياز جميع بوابات القبول المتفق عليها.
