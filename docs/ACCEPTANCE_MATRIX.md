## بيانات يجب تسجيلها لكل اختبار ميداني

- رقم الحالة وإصدار البرنامج وcommit SHA.
- بيئة Windows ونسخة PostgreSQL وإعداد الشبكة.
- المستخدم والدور والصلاحيات.
- أرقام المستندات والتشغيلات التي أنشئت.
- النتيجة المتوقعة والنتيجة الفعلية.
- صورة/فيديو أو سجل API/SQL يدعم النتيجة.
- اسم مسؤول الاختبار وتاريخ الاعتماد.

## قرار التسليم

لا يعتمد النظام للإنتاج حتى تغلق حالات UAT الحرجة، ويوقع ممثلو المشتريات والمخزن والجودة والإنتاج والمبيعات والحسابات والإدارة على نتائجها.
