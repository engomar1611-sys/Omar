# وثيقة المتطلبات — NEW FEED ERP

## 1. الهدف والنطاق
إنشاء نظام ERP صناعي لإدارة مصنع أعلاف واحد وخط إنتاج واحد في المرحلة الأولى، مع 10–30 مستخدماً، وقابلية التوسع إلى مصانع وخطوط وأنواع أعلاف إضافية دون إعادة تصميم جوهرية.

المنصات: خادم مركزي، تطبيق Windows، وواجهة Web. اللغة الأساسية العربية، والعملة الافتراضية EGP قابلة للتغيير. قاعدة البيانات المستهدفة PostgreSQL.

## 2. أنواع الأعلاف والمنتجات
- أنواع الأعلاف كيانات ديناميكية قابلة للإضافة والتعديل والتعطيل.
- أمثلة أولية: دواجن، مواشي/أبقار، أسماك، أغنام/ماعز، وأي أنواع أخرى.
- لكل منتج وحدة قياس وتعبئة ومواصفات غذائية وجودة وحدود قبول.
- كل منتج يمكن أن يرتبط بأكثر من تركيبة ذات إصدارات فعالة ومؤرخة.
- لا يسمح بتغيير تركيبة معتمدة بأثر رجعي؛ تنشأ نسخة جديدة مع سجل اعتماد.

## 3. الموديولات الوظيفية
1. الإدارة: الشركة والمصنع، المستخدمون، الأدوار والصلاحيات، الإعدادات، الورديات، الإشعارات، سجل التدقيق.
2. المشتريات: طلب شراء، عروض موردين، أمر شراء، استلام، فاتورة، مصروفات إضافية، مرتجع، دفعات المورد.
3. المخازن: تعريف الأصناف والوحدات والمخازن والمواقع، أرصدة، حركات، تحويلات، جرد، تسويات معتمدة، حد إعادة الطلب، تشغيلات وصلاحية.
4. التركيبات: مكونات ونسب، احتساب الكمية والتكلفة النظرية، مواصفات غذائية، إصدار ومراجعة واعتماد.
5. الإنتاج: تخطيط وجدولة، أمر إنتاج، حجز وصرف خامات، مراحل تشغيل، استهلاك فعلي، فاقد، إنتاج تام، إغلاق وتسوية.
6. الجودة: خطط أخذ عينات، فحص خامات وتحت التشغيل ومنتج تام، قبول/رفض/حجز، إعادة فحص، شهادة تحليل.
7. المبيعات: عروض، طلبات، أوامر بيع، حجز مخزون، تسليم، فواتير، خصومات معتمدة، مرتجعات، تحصيل وائتمان.
8. النقل والتوزيع: سيارات وسائقون ورحلات تحميل وتسليم وتكاليف نقل.
9. الحسابات: دليل حسابات، قيود مزدوجة، يومية وأستاذ، مراكز تكلفة، خزائن وبنوك، سندات قبض وصرف، تسويات، إقفال، ميزان مراجعة وقوائم مالية.
10. التكاليف: تكلفة معيارية وفعلية للخامات والعمالة والطاقة والتشغيل والصيانة والتعبئة والنقل، تكلفة الطن، فروق التكلفة والربحية.
11. الصيانة: الأصول والمعدات، أوامر الصيانة، الوقائية والطارئة، قطع الغيار والتوقفات.
12. الموارد البشرية: الموظفون والورديات والحضور والرواتب وفق نطاق يعتمد لاحقاً.
13. التقارير ولوحات المعلومات: المخزون، المشتريات، المبيعات، الإنتاج، الجودة، الهالك، التكلفة، الربحية، الحسابات، أعمار الديون.
14. المستندات والموافقات: مسارات اعتماد قابلة للضبط ومرفقات وإصدارات.

## 4. دورة تشغيل نموذجية
طلب شراء ← أمر شراء ← استلام خامات ← فحص جودة ← إتاحة المخزون المقبول ← اعتماد تركيبة ← أمر إنتاج ← حجز وصرف خامات ← تسجيل مراحل الإنتاج والاستهلاك ← فحص المنتج النهائي ← إتاحة المنتج المقبول للبيع ← أمر بيع وتسليم وفاتورة ← تحصيل ← قيود وتكلفة وربحية.

## 5. ضوابط إلزامية
- لا صرف خامات أو بيع منتج محجوز/مرفوض جودة.
- لا اعتماد أمر إنتاج دون تركيبة سارية ومعتمدة.
- لا ترحيل مالي دون قيد مزدوج متوازن.
- لا تعديل أو حذف مستند مرحّل؛ التصحيح بمستند عكسي وصلاحية واعتماد.
- منع المخزون السالب افتراضياً، وأي استثناء يحتاج قراراً صريحاً وصلاحية.
- كل حركة مرتبطة بالمستخدم والتاريخ والمستند والمخزن والتشغيلة.
- فصل الكميات المحجوزة والمرفوضة وتحت الفحص عن المتاح.
- دعم الإقفال والفترات المالية ومنع الترحيل إلى فترة مغلقة.

## 6. الصلاحيات
أدوار مبدئية: مدير النظام، مدير المصنع، المشتريات، أمين المخزن، مراقب الجودة، مهندس/مشرف الإنتاج، المبيعات، الحسابات، مدير مالي، الصيانة، مراقب/مدقق. الصلاحيات على مستوى الشاشة والإجراء والمستند والقيمة الحساسة، مع فصل المنشئ عن المعتمد عند الحاجة.

## 7. متطلبات غير وظيفية
- واجهة عربية RTL، مع تصميم قابل لإضافة الإنجليزية.
- اتصال آمن HTTPS، وإدارة جلسات وكلمات مرور وتحديد محاولات الدخول.
- نسخ احتياطي مجدول واختبار استعادة موثق.
- سجل تدقيق غير قابل للتعديل من المستخدم العادي.
- معاملات قاعدة بيانات ذرية، قيود وفهارس مناسبة، ومعالجة التزامن.
- استيراد وتصدير Excel/PDF وفق الصلاحيات.
- مراقبة صحة الخدمة والسجلات والأخطاء.
- تحديثات موقعة أو موثوقة، مع خطة رجوع للإصدار السابق.
- فصل بيئة التطوير والاختبار والإنتاج.

## 8. قرارات تحتاج اعتماداً قبل البناء النهائي
- عدد المخازن ومواقع التخزين الفعلية.
- مراحل خط الإنتاج الفعلية وأجهزة القياس/الميزان والربط المطلوب.
- معايير الجودة وحدود كل نوع علف.
- سياسة تكلفة المخزون (متوسط مرجح/ FIFO) والتكاليف الصناعية غير المباشرة.
- الضرائب والفوترة الإلكترونية والمتطلبات القانونية المطبقة.
- سياسة الائتمان والخصومات والعمولات.
- تفاصيل الموارد البشرية والرواتب.
- هل توجد فروع/شركات أو عملات متعددة مستقبلاً.
- متطلبات ترحيل البيانات القديمة.

لا تُعتبر هذه القرارات محسومة ما لم يعتمدها صاحب المشروع كتابةً.
