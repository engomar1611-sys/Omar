# NEW FEED ERP

نظام ERP صناعي متكامل لإدارة مصانع الأعلاف، مصمم لدعم أنواع متعددة من الأعلاف وليس أعلاف الدواجن فقط.

## نطاق النظام المعتمد مبدئياً

- مصنع واحد وخط إنتاج واحد في المرحلة الأولى.
- 10–30 مستخدماً.
- واجهات عربية، مع دعم الجنيه المصري كعملة افتراضية قابلة للضبط.
- تطبيق Windows + واجهة Web + خادم مركزي.
- قاعدة بيانات PostgreSQL.
- أنواع أعلاف ديناميكية قابلة للإضافة، مثل أعلاف الدواجن والمواشي والأبقار والأسماك والأغنام والماعز.
- تركيبات مستقلة وإصدارات معتمدة ومواصفات جودة لكل منتج.
- إدارة المشتريات والمخازن والتشغيلات والإنتاج والجودة والمبيعات والحسابات والتكاليف والصيانة والتقارير.
- تتبع كامل للخامات والتشغيلات والمنتجات النهائية (Batch Traceability).
- صلاحيات حسب الدور، موافقات، وسجل تدقيق.
- HTTPS، نسخ احتياطي واستعادة، وتحديثات آمنة.

## دورة التشغيل الرئيسية

المشتريات والاستلام ← فحص الخامات ← اعتماد التركيبة ← أمر الإنتاج وصرف الخامات ← التصنيع ← فحص المنتج النهائي ← التخزين ← البيع والتسليم ← التحصيل والقيود والتكاليف.

## مبدأ التصميم

أنواع الأعلاف والمنتجات والتركيبات ومواصفات الجودة ليست قيماً ثابتة داخل الكود؛ بل بيانات قابلة للإدارة من النظام. ويجب أن تكون كل حركة مخزون أو إنتاج أو مالية مرتبطة بمستند مصدر واضح، مع دعم العكس المحاسبي والمخزني وفق الصلاحيات.
